 WoWTranslateControl 更新日志 · by ijnokmsc
==============================================================

2.1.1 （2026-09-13）
--------------------------------------------------------------
【修复】
* 翻译消息丢失发送者：部分译文只剩正文、看不到谁发的
  （频道名 / 玩家名链接现在完整保留在译文头部）

【变更】
* DLL 文件日志默认关闭：如需排错，在游戏目录 WoWTranslateDirect.json
  中将 "log" 改为 true 后，游戏内 /reload 生效
* 控制台启动时自动比对游戏目录 DLL 与本地资源的版本
  （MD5），不一致自动重新部署——更新控制台后忘记重新部署
  也能自愈

2.1.0 （2026-09-13）
--------------------------------------------------------------
【新增】
* DLL 全自治：游戏内不再需要安装任何插件——DLL 自己捕获聊天、
  送控制台翻译、写回聊天框（原 GS 插件链路转为备用轨道）
* 外发翻译（中文→英文）：自己发的中文自动以英文发出，
  三种模式可选：关闭 / 只发英文（失败发原文） / 原文+英文都发
* 译文显示模式可选：译文替换原文 | 原文+译文（前缀追加），
  游戏内打 /reload 立即生效，无需重启客户端
* 端口冲突自动回退：8080 被占用时自动换下一个可用端口，
  并自动同步游戏目录配置（DLL 端点跟着变）
* 单实例保护：重复启动自动提示，防止端口占用冲突
* llama.cpp 便携化：默认使用程序目录下的 llama.cpp 文件夹
  （首次启动自动生成），推理线程数自动按 CPU 核心数适配
* 下载向导增强：
  - llama.cpp 下载完成后自动解压（含 CUDA 运行库包）
  - 识别手动放入的 llama-server.exe / 模型 gguf / 构建包
  - 「停止下载」按钮（取消并自动清理半截文件）
  - llama 目录大文件检测与「清理未使用大文件」按钮
    （区分使用中模型 / 未使用模型 / 遗留安装包 / 残留临时文件）
  - 手动下载指引（下载失败时给出地址与放置路径）
* 应用图标（任务栏 / 资源管理器 / 窗口）
* 首次使用引导：未安装 llama.cpp 时不再报错，自动跳过启动并指引用户

【修复】
* 中文系统频道不翻译：本地聊天、地下城向导、团队领袖、战场领袖
  等特殊频道头（全角冒号 / 中文频道名）完整支持
* 中文外发被误拦：外发请求不再受"已是中文"过滤规则影响
* 一系列乱码问题：
  - 译文开头出现 ?频道?
  - 译文出现 ⟦G12⟧ 之类占位符
  - [HC] 等标签被翻译成 [英雄的]（现原样保留）
* 偶发不翻译：引擎自动重试瞬时失败，并记录完整错误日志便于定位
* 首次使用（未安装 llama.cpp）时启动不再报错
* 下载中关闭窗口导致的文件占用与崩溃

【变更】
* 全链路 UTF-8：中文不再变成 ?（原 GS 插件的核心痛点）
* proxy_traffic.log 默认关闭（界面可开关，排错用）
* 缓存键升级：旧翻译缓存自动失效，不会被历史脏数据污染
* 过滤代理提示词与翻译方向随请求自动切换

2.0.0 及更早为内部开发版本，未对外发布。
