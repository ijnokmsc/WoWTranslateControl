==============================================================
 WoWTranslateControl 使用教程 (v2.1.2 · ijnokmsc)
 WoW 3.3.5 客户端 聊天实时翻译（英文→中文 / 中文→英文外发）
==============================================================

【一、快速开始（三步）】
  1. 运行 WoWTranslateControl.exe
  2. 点「环境检测与下载向导」→ 下载 llama.cpp 与翻译模型
     （详细步骤见【三】）
  3. 点「一键启动全部」

【二、文件说明】
  WoWTranslateControl.exe   主程序（.NET 运行时已内置，无需安装任何环境）
  assets\direct-dll\        游戏注入用 DLL（dinput8.dll + WoWTranslateDirect.dll）
  assetspp.ico            程序图标
  glossary.json             术语表（已内置 240+ 条 WoW 术语）
  llama.cpp\                llama.cpp 与模型存放目录（首次启动自动生成）
  settings.json             配置文件（首次启动自动生成）
  cache.json                翻译缓存（自动生成，可随时在界面清空）
  更新日志.txt               版本更新记录

  ※ 程序有单实例保护：重复运行会提示"已在运行中"（防端口冲突）。
    若最小化到了托盘，请从托盘双击恢复。

【三、首次部署（从零开始）】
  1. 点「环境检测与下载向导」：
     - llama.cpp：选 CPU（AVX2）版 → 「下载到 llama 目录」
       * 下载完成后自动解压，无需手动操作
       * GitHub 直连较慢或失败：按日志里的地址手动下载 zip，
         放入 llama.cpp\ 目录后再点一次下载（会触发自动解压），
         或自行解压，确保目录里有 llama-server.exe（向导会自动识别"已就绪"）
     - 翻译模型：首选「混元 Hy-MT2 1.8B」（约 1.1GB，hf-mirror 国内直连）
       * 下载慢也可手动下载 gguf 放入 llama.cpp\ 目录，向导会识别为已就绪
     - 点「应用此模型」写入配置
  2. 回主窗口，点「启动 llama-server」，等日志显示模型加载完成
  3. 点「启动过滤代理」（或直接点「一键启动全部」）
     - 端口：8080 = 过滤代理（游戏用），8081 = llama-server（内部）
     - 8080 被占用会自动换下一个可用端口并同步游戏配置
     - 首次监听若弹 Windows 防火墙提示，选择"允许"

【四、游戏端部署（只需一步）】
  1. 完全退出游戏客户端（Wow.exe 运行中不会改动文件）
  2. 主窗口「游戏目录与部署」填入客户端根目录
     （需含 Wow.exe 与 Data 文件夹），程序会：
     - 自动校验目录有效性
     - 自动部署翻译 DLL（默认主推轨道，无需选择）
     - 首次部署前自动备份现有 DLL 到 wtc_backup\ 文件夹
  3. 「插件 DLL 翻译选项」按需调整（改完游戏内 /reload 生效）：
     - 译文显示：译文替换原文 | 原文+译文（前缀追加）
       ※ EUI 用户注意：EUI 接管了聊天显示，"替换"暂不可用，
         表现为原文+译文都显示；巨龙UI/原生界面不受影响
     - 外发翻译（中文→英文）：关闭 | 只发英文 | 原文+英文都发

【五、进入游戏】
  1. 聊天框出现：
     [WTC] WoWTranslateDirect 2.1.2 by ijnokmsc (driver v32, ...)
     即部署成功（横幅在进入世界约 1 秒后出现）
  2. 英文聊天 → 自动显示中文译文（综合聊天框）
  3. 你发的中文 → 自动以英文发出（约 1-3 秒；超时 25 秒发原文兜底）
  4. 改了控制台设置后：游戏内打 /reload 立即生效

【六、常用设置说明】
  - 按频道过滤（C0-C8）：不想翻译的频道（如世界频道）关掉对应勾选，
    即时生效
  - 过滤规则 R0-R8（左栏最下方）：系统噪音过滤（战斗日志/拾取播报等），
    默认全开即可
  - 术语表管理：词条 = 英文原文 → 中文译名，保存后自动生效
    （例：Al'ar=奥尔、LFM=求组，可持续补充提升译名一致性）
  - 响应缓存：相同原文直接复用译文，不重复调用模型；界面可「清空缓存」
  - 实时流量：查看每条消息走了哪条规则/是否缓存命中
  - 外发等待时间：默认 25 秒，可在游戏目录 WoWTranslateDirect.json
    的 outTimeout 调整（游戏内 /reload 生效）

【七、常见问题】
  Q：双击运行没反应，或报 Unknown Hard Error？
  A：① 需要 Windows 10 及以上（.NET 10 不支持 Win7/8）；
     ② 首次启动（或刚更新后）Windows/杀毒软件扫描 165MB 单文件
        程序可能等待十几秒——属正常，等窗口出现即可；
     ③ 网络下载获得的话：右键 exe → 属性 → 勾选"解除锁定"；
     ④ 程序目录加入杀软白名单；仍失败请反馈系统版本与
        startup.log（程序目录内，若存在）。

  Q：双击运行提示"已在运行中"？
  A：程序在托盘。双击托盘图标恢复；确需重启请先从托盘菜单退出。

  Q：启动 llama-server 报"未找到可执行文件/模型"？
  A：llama 目录或模型文件名与实际不符——检查设置里这两项与
     llama.cpp\ 目录内容一致（模型是完整 gguf 文件名，含大小写）。

  Q：下载一直失败/卡住？
  A：llama.cpp 的 zip 走 GitHub 直连，模型走 hf-mirror。均支持
     手动下载后放入 llama.cpp\ 目录（详见第三步），向导会自动识别。

  Q：游戏里没出现 [WTC] 横幅？
  A：确认控制台「游戏目录与部署」状态显示有效且已部署；完全重启
     过游戏客户端。

  Q：翻译不工作但横幅正常？
  A：确认 llama-server 与过滤代理都在运行。排错：控制台勾选
     「DLL 日志」和「写入文件日志」后复现一次，把
     WoWTranslateDirect.log 和 proxy_traffic.log 发出来即可定位。

  Q：EUI 下译文没有替换原文？
  A：EUI 接管了聊天显示路径，"替换"暂不支持（自动表现为追加显示）。
     巨龙UI/原生界面不受影响。

  Q：游戏目录 WoWTranslateDirect.json 改坏了？
  A：控制台里随便改动一个翻译选项再改回，即可重写。

【八、卸载】
  1. 控制台「游戏目录与部署」点「高级：切回 GS 备用轨道」（或删除
     游戏目录的 dinput8.dll / WoWTranslateDirect.dll / dlls.txt /
     WoWTranslateDirect.json）
  2. 退出并删除本程序目录即可。设置/缓存/术语表都在程序目录内，无残留。
