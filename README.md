# WoWTranslateControl

WoW 3.3.5 客户端聊天实时翻译控制台 —— 纯本地运行（llama.cpp 本地模型）：英文聊天实时转中文显示，你发的中文自动翻成英文发出。

## 这是什么

给魔兽世界 3.3.5a 客户端做的聊天实时翻译工具：

- **接收**：别人的英文聊天自动翻译成中文，显示在你的聊天框里
- **外发**：你输入的中文自动翻译成英文发出（英文队友直接可读）
- **纯本地**：默认用 llama.cpp + 本地 gguf 模型推理，聊天文本不出你的电脑；也可手动切换 OpenAI / 谷歌接口

工作方式：控制台（WPF 单文件 exe）在本机启动翻译服务；游戏目录部署 `dinput8.dll` 代理 + `WoWTranslateDirect.dll` 引擎，直接在客户端进程内捕获并改写聊天。

## 功能特性

- 实时双向翻译：外发约 1–3 秒出译文，超时（默认 25 秒）自动发原文兜底
- 发送消息过滤器：免翻译前缀规则（`.` / `。` 开头的私服命令恒放行，带中文参数也不怕）+ 说/喊/密语/队伍/公会/官员/团队/团队警告/战场/世界 十个外发频道独立开关
- 术语表：内置 240+ 条 WoW 术语，可持续补充（如 `Al'ar=奥尔`），保证译名一致
- 双层翻译缓存：高频短句进热层持久保留，重复消息零模型调用
- 按频道过滤（C0–C8）+ 系统噪音过滤（战斗日志 / 拾取播报等，默认全开即可）
- 多客户端画像：按客户端 exe 指纹自适应，Triumvirate、FrostmourneRebuffed 等加固客户端已适配（Grimfall 不兼容，已知限制）
- llama-server 内存监控：工作集超阈值自动重启回收，进程崩溃自动拉起
- 实时流量视图；`-Debug` 启动参数一键开启全部日志（DLL 日志 / 代理流量 / 内存采样），排错有据可查

## 环境要求

- Windows 10 及以上（.NET 10 运行时已内置在单文件 exe，无需安装任何环境）
- WoW 3.3.5a 客户端（目录含 `Wow.exe` 与 `Data` 文件夹）
- 首次使用通过内置向导下载 llama.cpp（CPU AVX2 版）与翻译模型（首选混元 Hy-MT2 1.8B，约 1.1GB，走 hf-mirror 国内直连）

## 快速开始

1. 从 [Releases](https://github.com/ijnokmsc/WoWTranslateControl/releases) 下载 zip 解压，运行 `WoWTranslateControl.exe`
   （首次启动或刚更新后，杀软扫描 165MB 单文件可能等待十几秒；网络下载的文件请先右键 → 属性 → 解除锁定）
2. 点「环境检测与下载向导」→ 下载 llama.cpp 与翻译模型 → 点「应用此模型」
3. 点「一键启动全部」（8080 = 过滤代理，8081 = llama-server；端口占用自动顺延）
4. **完全退出游戏**，主窗口「游戏目录与部署」填入客户端根目录 → 自动部署 DLL（首次部署自动备份原文件到 `wtc_backup\`）
5. 进游戏，聊天框出现 `[WTC] WoWTranslateDirect 3.1.1 by ijnokmsc (driver v45, ...)` 横幅即部署成功

改了控制台设置后，游戏内 `/reload` 立即生效。详细步骤与常见问题见 [使用教程.txt](使用教程.txt)，版本变更见 [更新日志.txt](更新日志.txt)。

## 常用设置

- 译文显示：替换原文 / 原文+译文（EUI 接管聊天显示时"替换"不可用，自动表现为追加显示；巨龙 UI / 原生界面不受影响）
- 外发翻译：关闭 / 只发英文 / 原文+英文都发；不想翻译的频道直接取消勾选
- 术语表管理：词条 = 英文原文 → 中文译名，保存即生效
- 卸载：主窗口「卸载 Direct DLL」一键清理，并自动还原你部署前原有的文件

## 隐私与安全

- 默认翻译全部在本机完成（llama.cpp 本地模型）；仅当你手动切换到 OpenAI / 谷歌接口时，聊天文本才会发送给相应服务商
- 游戏目录只写入 `dinput8.dll` / `WoWTranslateDirect.dll` / `dlls.txt` / `WoWTranslateDirect.json` 四个文件，原文件自动备份，卸载可完整还原
- 程序有单实例保护，配置 / 缓存 / 术语表都在程序目录内，删除目录即彻底移除、无残留
